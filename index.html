How it works & how accurate it is

  1. Stem separation (optional, local helper): Demucs htdemucs_6s splits the song into vocals, guitar, piano, bass, drums and other, so the guitar mode hears only guitar and the melody modes hear only the singer or the lead.
  2. Note transcription: in guitar mode, TabForge's own model: Spotify's Basic Pitch fine-tuned on the real tabs of GuitarSet and IDMT-SMT-Guitar (real palm mutes, bends, slides), plus high-gain amps and thousands of synthetic metal riffs, so it handles distortion and fast chugs. Melody modes use the original Basic Pitch, which is better on voice and keys. Both run in your browser.
  3. Automatic sensitivity: the note thresholds are picked per song from how strongly the network reacts, using a rule calibrated on held-out recordings.
  4. Music analysis: beats tracked with dynamic programming (drifting tempos are followed too), downbeats found, strummed chords grouped, notes snapped to a 16th-note grid, key and chords detected.
  5. Melody modes: a Viterbi search picks the most prominent line frame by frame, preferring loud and high notes and smooth motion, then moves it by octaves into the sweet spot of the guitar.
  6. Fingering: every chord gets its playable shapes (one note per string, at most a 4-fret stretch). A second Viterbi pass picks the sequence a guitarist would play: its costs were fitted to real tabs, and a string head in the model listens to the timbre to tell which string each note is on.

Measured on recordings the model never saw: about 83% of notes right on clean guitar or a separated guitar stem, 71% through a high-gain amp, 66% in a full metal mix (stock Basic Pitch: 38%), 74% on real electric playing with palm mutes and bends (stock: 51%). No automatic transcriber is perfect, so turn on stem separation, pick the right tuning, and check by ear with the synced player. If notes are missing, untick Auto and raise the sensitivity; use ½× / 2× if the bars look stretched.
